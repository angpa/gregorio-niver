# Cumple Pablo — MÖ Oráculo 🔮

Invitación interactiva al cumpleaños de Pablo, basada en el sistema de adivinación tibetano **MÖ**.

## Features

- 🌀 **Mandala 3D** — Fondo animado con anillos concéntricos rotatorios (react-three-fiber)
- 🎲 **Dados Tibetanos** — Animación de dados con sílabas tibetanas
- 📖 **36 Combinaciones** — Base de datos completa del sistema MÖ
- 🐱 **Intervención Gatuna** — Leia, Alberta, Deimos, Pastelito y Skinny anulan la mala suerte
- 📱 **Responsive** — Optimizado para móviles

## Stack

- **Next.js 16** (App Router)
- **React Three Fiber** (Three.js)
- **Tailwind CSS 4**
- **TypeScript**

## Dev

```bash
npm install
npm run dev
```

## Deploy

```bash
npm run build
```

Deploy en Vercel o cualquier plataforma compatible con Next.js.
